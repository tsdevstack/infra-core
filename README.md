# @tsdevstack/infra-core

Shared infrastructure utilities for [tsdevstack](https://tsdevstack.dev).

Provider-agnostic helpers and cloud client wrappers for GCP, AWS, and Azure, used internally by [`@tsdevstack/cli-infra`](https://github.com/tsdevstack/cli-infra).

## Source-available mirror

This repository mirrors the `@tsdevstack/infra-core` source from the tsdevstack monorepo. It is consumed by `@tsdevstack/cli-infra` and bundled into the [`@tsdevstack/cli`](https://www.npmjs.com/package/@tsdevstack/cli) binary, so it is not published to npm or installed on its own.
